Installation terminée

Encore deux réglages et Mon EcoleDirecte est prêt.

1 Ajouter l'icône sur l'écran d'accueil

L'application s'ouvrira dans sa propre fenêtre, sans onglet en double.

  • Dans Chrome, menu ⋮ (en haut à droite) → Installer et créer un raccourci.
  • Dans la fenêtre qui s'ouvre, choisissez la première option (« Installer »).
  • Si elle indique « Cette appli est déjà installée » mais que l'icône n'est plus sur l'écran d'accueil (supprimer l'icône ne désinstalle pas toujours l'application) : Réglages Android → Applications → Mon EcoleDirecte → Désinstaller, puis rechargez cette page et recommencez. Vos données (mémos, session) sont conservées par Chrome.
  • N'utilisez pas « Créer un raccourci » : ce raccourci s'ouvre dans un onglet de Chrome, pas dans la fenêtre de l'application.

✓ Icône installée

2 Autoriser Termux en arrière-plan

Réglages Android → Applications → Termux → Batterie → Sans restriction. Sinon Android peut arrêter le serveur local.

✓ Au quotidien

  • Ouvrez simplement l'icône Mon EcoleDirecte.
  • Si le serveur est arrêté (après un redémarrage du téléphone par exemple), la page d'attente propose Démarrer le serveur : appuyez dessus (puis sur Ouvrir si le Play Store s'affiche) et revenez dans l'application.
